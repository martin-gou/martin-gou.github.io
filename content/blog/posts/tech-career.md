# Navigating a career in tech

A tech career is rarely a straight line. Skills, interests, and opportunities change over time.

## Build visible proof of work

A portfolio of projects often communicates more than a list of claimed skills.

Useful signals include:

- code repositories
- project writeups
- demos
- technical notes

## Learn in layers

I find it useful to grow in layers:

1. fundamentals
2. tools
3. systems thinking
4. communication

Strong fundamentals make it easier to learn new frameworks later.

## Collaboration matters

Technical skill is important, but so is the ability to:

- ask good questions
- explain tradeoffs
- document decisions
- work with feedback

## Long-term view

A sustainable career is built through curiosity, consistency, and the habit of finishing meaningful work.
