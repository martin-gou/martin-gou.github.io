# Mastering JavaScript: tips and tricks

This is a lightweight note for practices that improve JavaScript code quality.

## Prefer clarity over cleverness

Short code is not always better. Future-you should understand the code quickly.

## Use small functions

Split complex logic into focused functions:

- easier to test
- easier to debug
- easier to reuse

## Treat async code carefully

When working with async/await:

- handle loading states
- catch errors explicitly
- avoid mixing many async responsibilities in one function

## Debug with intent

Good debugging is a skill:

- reproduce the bug
- narrow the scope
- inspect assumptions
- fix the root cause

## Keep learning by rewriting

Revisit old code and refactor it after you learn a better pattern. That is one of the fastest ways to improve.
