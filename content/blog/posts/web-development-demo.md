# Getting started with web development

Web development combines creativity and technical problem solving. If you want to build websites or understand how the web works, learning the basics is a great starting point.

## The three core technologies

### 1. HTML

HTML gives structure to a page. Think of it as the skeleton.

```html
<!doctype html>
<html>
  <head>
    <title>My First Webpage</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is my first webpage.</p>
  </body>
</html>
```

### 2. CSS

CSS controls visual style and layout. It is how the page looks and feels.

```css
body {
  font-family: Arial, sans-serif;
  background: #f0f0f0;
  padding: 20px;
}
```

### 3. JavaScript

JavaScript makes pages interactive and dynamic.

```js
document.getElementById('myButton').addEventListener('click', () => {
  document.getElementById('myText').innerHTML = 'Button was clicked!';
});
```

## A practical beginner path

1. Learn HTML structure and common tags
2. Learn CSS selectors and layout basics
3. Learn JavaScript fundamentals
4. Build small projects that combine all three
5. Learn responsive design
6. Explore frameworks like React

## Tools that help

- VS Code (or any editor you like)
- Browser devtools
- Git for version control

## Final advice

Start simple. Build often. Do not wait until you feel "ready" to make projects.
